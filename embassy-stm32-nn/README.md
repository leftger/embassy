# embassy-stm32-nn

Embassy companion driver integrating [`embedded-nn`](https://crates.io/crates/embedded-nn) with the STM32N6 Neural-ART (ATON) NPU peripheral.

## Features

- **Automatic Cache Coherency**: Handles Cortex-M55 D-cache clean (`mcu_clean_range`) before NPU execution and invalidation (`mcu_invalidate_range`) after completion to prevent stale cache hazards.
- **Zero-Copy Tensor Relocation**: Directly links `embedded-nn` [`TensorView`] instances and 8-byte aligned slices to ST Edge AI Epoch Controller (`EcBinary`) relocations.
- **Hybrid Execution Pipelines**: Run NPU hardware epochs alongside CPU software fallback epochs (Softmax, GELU, dequantization, anomaly detection, recurrent cells) in a single asynchronous pipeline.
- **High-Level Model Runner**: [`NpuRunner`] provides simple `.infer(&input, &mut output).await` syntax over Embassy async tasks.

## Quickstart

```rust,no_run
#![no_std]
#![no_main]

use embassy_executor::Spawner;
use embassy_stm32::{bind_interrupts, npu, peripherals};
use embassy_stm32::npu::ecloader::EcBinary;
use embassy_stm32_nn::{BlobSession, NpuRunner, ArgMaxEpoch};
use static_cell::StaticCell;

bind_interrupts!(struct Irqs {
    NPU0 => npu::InterruptHandler<peripherals::NPU>;
});

// Generated by ST Edge AI tooling
static EC_BIN: &[u64] = &[/* ... */];
static BLOB: StaticCell<[u64; 3800]> = StaticCell::new();

#[embassy_executor::main]
async fn main(_spawner: Spawner) {
    let p = embassy_stm32::init(Default::default());
    let mut npu = npu::Npu::new(p.NPU, Irqs);

    let bin = EcBinary::new(EC_BIN).unwrap();
    let blob = BLOB.init([0; 3800]);
    let session = BlobSession::new(bin, blob).unwrap();

    let mut runner = NpuRunner::new(&mut npu, session);

    let input_data = [0i8; 128];
    let mut logits = [0i8; 10];
    let mut predicted_class = 0usize;
    let mut confidence = 0i8;

    let mut postproc = ArgMaxEpoch::new(&logits, &mut predicted_class, &mut confidence);
    runner.infer_with_postproc(&input_data, &mut logits, &mut postproc).await.unwrap();
}
```
